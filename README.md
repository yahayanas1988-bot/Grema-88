# Grema-88

Site de l'agence **Grema 88** : catalogue d'applis, livres, vidéos et boutique, en français, anglais, arabe et allemand.

En ligne sur GitHub Pages : https://yahayanas1988-bot.github.io/Grema-88/ (publié automatiquement à chaque changement sur `main`, voir `.github/workflows/pages.yml`).

- `index.html` : le site
- `admin.html` : l'Espace Grema, pour ajouter ou modifier les publications
- `contenu.js` : le contenu du site (généré par l'Espace Grema)
- `agent-patron/` : l'espace Agent Patron, tableau de bord des agents IA (données dans `agent-patron/agents.js`)
- `apps/`, `images/`, `videos/` : démo Nessa Tazo Kussa, images et dessin animé
- `agent-expert/` : l'agent IA expert en équipe (Python), non publié sur le site

Mode d'emploi complet : voir `LISEZ-MOI.txt`.
